### Gotcha worth remembering
A 200 from a Greenhouse slug is not proof of identity. The variant "shield" returns a
GitHub Pages demo board ("Copy of Avenger", Beijing) — not Shield AI. verify.py now
requires a guessed variant to prove itself via the /v1/boards/{slug} name (Greenhouse)
or the slug appearing in the posting URL path (Lever/Ashby). Seeded slugs are taken at
face value because many real boards apply through a custom domain, so the apply-URL
host proves nothing.

### Two bugs found and fixed by running it for real
- HN thread selection returned the March 2020 thread. Algolia's /search endpoint is
  relevance-ranked and returns 20 arbitrary hits, none recent, so "newest hit"
  was newest-of-an-old-sample. Now queries /search_by_date filtered to the
  whoishiring account, with /search kept as a fallback.
- On Windows stdout is cp1252, so the digest wrote an em dash as byte 0x97 and any
  character outside cp1252 would have raised UnicodeEncodeError *after* the whole
  run completed. main() now reconfigures stdout/stderr to UTF-8 with
  errors="replace".

16. Tiering + `--tier`. Tier 1 = support/solutions/implementation/TAM with no

    time, so no schema migration was needed.
17. Pushed public: https://github.com/kurmudgen/jobwatch
18. Two filter bugs found by actually reading the tier 1 output:
    - Boilerplate "remote" was rescuing on-site roles. Palantir puts "there are a
      few roles that allow for 'Remote' work on an exceptional basis" in every
      description; that one word cancelled the on-site rule for 62 roles whose
      location reads "(onsite)"/"(hybrid)", two of which reached tier 1. The
      escape hatch is now per field. First attempt at the fix silently did nothing
      because _phrase_re("remote -") collapses to a bare \bremote\b - entries are
      now asserted multi-word and tested.
    - Bare "secret" flagged every Supabase support role as needing a clearance
      ("our globally distributed team is our secret weapon"). It now has to sit
      within a few words of "clearance", or be "top secret".
19. Rebuilt jobwatch.db from scratch (approved) so the stored set matches the
    current rules. 224 matches: Tier 1 = 82, Tier 2 = 66, Tier 3 = 76.
